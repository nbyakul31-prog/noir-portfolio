# NOIR PORTFOLIO - Lance Britaine Recto

> Full-Stack Developer. ASEAN Delegate 2026. QCU BSIT Undergraduate.

A cinematic, dark-mode portfolio site built with pure HTML, CSS, and vanilla JavaScript.
No frameworks. No build tools. No dependencies. Just raw engineering and aesthetic.

---

## Stack

| Layer | Tech |
|---|---|
| Markup | Semantic HTML5 |
| Styling | Vanilla CSS (custom properties, glassmorphism, keyframe animations) |
| Logic | Vanilla JavaScript (Web Audio API, Canvas API) |
| Fonts | Inter, Syne, Space Grotesk, JetBrains Mono, Playfair Display, Bebas Neue |
| Hosting | Vercel Edge Network |

---

## Features

- Cinematic biometric intro (fingerprint scan, radar sweep, door animation)
- Noir glassmorphism aesthetic with teal/cyan accents and grain overlays
- Procedural audio engine (Web Audio API) + looping soundtrack
- Evidence Vault: filterable carousel of 40+ documented portfolio items
- 7 Core System Dossiers (URSPantropiko, MMFindr, Hudikatura, RRC, StuLife, MAYO, ASEAN 2026)
- Embedded Flappy Dev retro mini-game
- Animated radar skill matrix
- Infinite marquee carousels rendered from JS asset data
